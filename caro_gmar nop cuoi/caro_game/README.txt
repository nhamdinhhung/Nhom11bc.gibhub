=== Cờ Caro — AI Edition ===

Yêu cầu:
  Python 3.8+
  pygame

Cài đặt:
  pip install pygame

Chạy game:
  cd caro_game
  python main.py

Tính năng:
  - Chế độ Người vs AI và AI vs AI
  - Chọn độ sâu tìm kiếm: 1 / 2 / 3 / 4
  - Chọn thuật toán: Minimax hoặc Alpha-Beta Pruning
  - (Chế độ AI vs AI) mỗi AI có thể dùng thuật toán khác nhau
